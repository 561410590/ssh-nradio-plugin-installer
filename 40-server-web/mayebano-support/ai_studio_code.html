Full Setup Pipeline

四步部署，开启全能体验

01

激活后台 SSH

这是所有后续操作的基础。请登录 NRadio Web 管理后台，在系统安全页中启用 SSH 服务。

http://192.168.66.1/cgi-bin/luci/admin/system/security
一键跳转至安全设置页

* 开启 SSH 后，务必点击右下角的【保存并应用】。

02

准备 SSH 工具

根据您的系统平台，选择合适的 SSH 客户端。建议使用如下软件：

MobaXterm (Win推荐)
FinalShell (中文首选)
Putty / XShell

登录参数：

  • • 主机: 192.168.66.1
  • • 端口: 22
  • • 用户: root
  • • 密码: 路由器 Web 登录密码
03

路由器在线下载

连接成功后，直接点击下方代码块复制命令，在终端粘贴并回车。脚本会自动完成下载、环境自检与机型识别。执行前会有免责声明，输入 y 同意即可进入全中文菜单。

cd /root && wget -O ssh-nradio-plugin-installer.sh https://nradio.mayebano.shop/ssh-nradio-plugin-installer.sh && sh ssh-nradio-plugin-installer.sh
点击复制代码
04

菜单化安装与验证

出现全中文交互菜单后，按数字键进行功能安装或卸载。完成后刷新 NRadio 官方应用商店确认效果。

出现菜单 = 环境识别通过
刷新商店 = 验证 UI 效果

重要安全准则

  • 请勿作为固件包在 Web 页面上传，仅限 SSH 终端内执行
  • 仅适用于官方 NROS 1.9 / 2.x 系列固件，标准 OpenWrt 不适用
  • 执行前务必确认路由器已成功连通互联网
  • 安装过程中严禁强行关闭终端窗口或断开电源
  • 仅限下方列出的受支持的极客官方机型
